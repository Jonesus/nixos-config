# nixos-config

NixOS (unstable) flake for a ThinkPad X13 Gen 2a: **niri** + **noctalia** shell + **noctalia-greeter**,
home-manager as a NixOS module, ghostty, LUKS2 + btrfs via disko.

```
flake.nix                    inputs: nixpkgs, home-manager, disko, nixos-hardware, noctalia, noctalia-greeter
hosts/x13/default.nix        host entry point (hostname, stateVersion, imports)
hosts/x13/disko.nix          disk layout: ESP + LUKS2 → btrfs subvolumes (@root @home @nix @log @docker @snapshots @swap)
hosts/x13/hardware-configuration.nix   regenerated by scripts/install.sh on the real machine
modules/nixos/base.nix       boot, nix, locale (fi keyboard, caps→esc), user, audio, firmware
modules/nixos/desktop.nix    niri, noctalia (+ NetworkManager/bluetooth/upower/ppd), greeter, fonts
modules/nixos/apps.nix       firefox, chrome, telegram, spotify, keepassxc, docker
home/                        home-manager: bash, git+gpg, ssh, ghostty, vim, vscode, claude-code, noctalia
home/niri/config.kdl         niri config, symlinked live from this checkout (edit → instant reload)
scripts/install.sh           wipe + install from the live ISO
```

## Install

1. Write the **NixOS minimal ISO** (x86_64, unstable or 26.05 — either works, the flake pins its own nixpkgs) to a USB stick and boot it (F12 on the ThinkPad).
2. Get online: plug in ethernet, or `nmtui` for Wi-Fi.
3. Get this repo and run the installer:
   ```sh
   nix-shell -p git
   git clone https://github.com/<you>/nixos-config && cd nixos-config
   sudo ./scripts/install.sh
   ```
   It asks for the disk encryption password, partitions with disko, generates
   `hardware-configuration.nix`, installs, and asks for your user password.
4. Reboot, unlock disk, log in via noctalia-greeter (session: niri).
5. Restore from backup: `~/.ssh`, `~/.gnupg` (git commit signing key `040E3EDC6AF623CE`), your files.
   Then `chmod 700 ~/.ssh ~/.gnupg`, and commit the generated hardware config.

## Day to day

| What | How |
|---|---|
| Apply changes | `nh os switch` (or `sudo nixos-rebuild switch --flake ~/nixos-config#x13`) |
| Update everything | `nix flake update && nh os switch` |
| Roll back | pick an older generation in the boot menu, or `sudo nixos-rebuild switch --rollback` |
| Try a package | `nix shell nixpkgs#<pkg>` |
| Edit niri config | edit `home/niri/config.kdl`; niri reloads on save; `niri validate` |
| Noctalia settings | `Mod+,` — GUI changes go to `~/.local/state/noctalia/settings.toml`; move keepers into `home/noctalia.nix` |

New files must be `git add`ed before a rebuild sees them (flakes only read tracked files).

## Keys (niri)

`Mod+Return` ghostty · `Mod+Space` launcher · `Mod+S` control center · `Mod+,` noctalia settings ·
`Mod+Q` close · `Mod+H/J/K/L` focus · `Mod+Shift+H/J/K/L` move · `Mod+1..9` workspaces ·
`Mod+O` overview · `Mod+R` cycle width · `Mod+F` maximize · `Mod+Alt+L` lock · `Mod+Shift+/` all keys
